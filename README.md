## 🚀 Hướng dẫn mở và chạy dự án (How to Run)

1. **Yêu cầu môi trường**:
   - .NET SDK (khuyên dùng .NET 8 / 9 / 10).
   - Visual Studio 2022 (v17.10 trở lên hỗ trợ định dạng .slnx) hoặc Visual Studio Code / Rider.

2. **Mở dự án**:
   - Mở file ASP.NET.slnx bằng Visual Studio.

3. **Chọn bài muốn chạy**:
   - Trong cửa sổ **Solution Explorer**, chuột phải vào project bạn muốn chạy (ví dụ Day2_... hoặc Day3_...).
   - Chọn **Set as Startup Project**.
   - Nhấn **F5** (Debug) hoặc **Ctrl + F5** (Run without debugging) để khởi chạy trên trình duyệt.
